# School AI Filter -- blocked domains
#
# One domain per line. Blocking a domain also blocks its subdomains, so
# "openai.com" covers "chat.openai.com" without a separate entry.
#
# Consumed two ways:
#   - scripts/setup-filter.sh turns this into dnsmasq address= rules
#   - AdGuard Home can subscribe to the raw file URL directly
#
# Exceptions go in allowlist.txt, which wins over anything here.
#
# NEVER add google.com or googleapis.com. Blocking either breaks Gmail,
# YouTube, Classroom and every Google sign-in, including for teachers.
