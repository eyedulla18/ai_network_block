School Wi-Fi Setup

Install one certificate so Google Search works on this network.

Download for iPhone / iPad
  1. Tap the button above, then tap Allow.
  2. Open Settings. Tap Profile Downloaded near the top.
  3. Tap Install (top right), enter your passcode, tap Install again.
  4. Go to Settings › General › About › Certificate Trust Settings.
  5. Turn on the switch next to School Filter CA. This step is required.

If nothing downloads, you are probably in the Wi-Fi sign-in popup. Open Safari and go to this page again.

Download for Android
  1. Tap the button above to save the file.
  2. Open Settings and search for CA certificate.
  3. Choose Install anyway, then pick the downloaded file.

Android apps ignore this certificate — only browsers use it. The Google app will not work for search; use Chrome instead.

Download for Mac
  1. Download the file, then double-click it to open Keychain Access.
  2. Find School Filter CA in the login keychain and double-click it.
  3. Expand Trust and set When using this certificate to Always Trust.
  4. Close the window and enter your password.

Firefox keeps its own certificate list. In Firefox: Settings › Privacy & Security › View Certificates › Import.

Download for Windows
  1. Download the file and double-click it.
  2. Click Install Certificate, choose Current User, then Next.
  3. Choose Place all certificates in the following store, click Browse, pick Trusted Root Certification Authorities, then Finish.

Firefox keeps its own certificate list and needs a separate import.
