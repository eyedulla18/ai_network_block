Download the certificate

  1. Tap Allow when iPhone asks to download a configuration profile.

  2. Open the Settings app.

    Leave this page open — come back to it when you are done.

  3. Tap Profile Downloaded near the top.

    Not there? Go to General › VPN & Device Management instead.

  4. Tap Install, enter your passcode, then tap Install again.

  5. Go to Settings › General › About and scroll to the bottom. Tap Certificate Trust Settings.

  6. Turn the switch on next to School Filter CA, then tap Continue.

    This step is required. Nothing works until this switch is on.

  7. Come back to this page. It will turn green on its own.

Nothing downloaded? You are probably in the small Wi-Fi sign-in window. Open Safari and go to this page again.

Download the certificate

  1. Tap the button above to save the file.

  2. Open Settings and search for CA certificate.

  3. Choose Install anyway, then pick the file you just downloaded.

  4. Come back to this page. It will turn green on its own.

Apps will still not work with Google. Android only uses this certificate in browsers. Use Chrome for searching, not the Google app.

Download the certificate

  1. Download the file, then double-click it. Keychain Access opens.

  2. Find School Filter CA in the login keychain and double-click it.

  3. Expand Trust, and set When using this certificate to Always Trust.

  4. Close the window and enter your password.

Firefox keeps its own certificate list: Settings › Privacy & Security › View Certificates › Import.

Download the certificate

  1. Download the file and double-click it.

  2. Click Install Certificate, choose Current User, then Next.

  3. Choose Place all certificates in the following store, click Browse, and pick Trusted Root Certification Authorities.

  4. Click Next, then Finish.

Firefox keeps its own certificate list and needs a separate import.
